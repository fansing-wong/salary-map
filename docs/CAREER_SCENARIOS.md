# 职业转型与优势衰减情景

这个分支服务于已有职业经历的人：当前优势仍有效时，怎样扩展选择；优势开始减弱或行业结构变化时，怎样提前准备替代路线。它和地域薪酬、出海身份路线并排比较，个人输入默认只保存在浏览器。

## 四条并行路线

每次规划至少比较以下路线，而不是只给一个“推荐转行”：

1. **留在当前职业并强化优势**：更新证书/工具、争取更高价值任务、换团队/行业/国家；标记哪些优势仍稀缺且有近期证据。
2. **相邻转型**：保留领域知识、客户/流程经验或可迁移技能，只补最短的技能缺口；优先找技能距离小、收入回撤较低的岗位。
3. **跨领域转型**：以兴趣、能力和目标生活方式重选职业，完整核算学习期、入门薪酬、资质和求职空档。
4. **防守与退出备份**：设置“优势衰减”触发条件，准备第二技能/副业/行业转移路线，并确定何时切换。

“优势衰减”由用户选可观测信号，例如：关键技能需求下降、当前岗位薪资/工时恶化、核心客户或业务流失、自动化替代任务比例提高、健康负荷超限、在目标移民地执照/签证受限。系统不会仅凭职业名称判定某人会被自动化替代。

## 用户输入与证据

- 当前及目标职业、行业、资历年限、主要任务、工作样本/成果。
- 自评技能及证据强度：有项目/作品/证书/绩效证明，还是仅为自我感觉。
- 可迁移优势：领域知识、沟通/管理、客户关系、行业合规、语言、地域经验、专业执照。
- 想保留或改变的条件：收入底线、工时/强度、远程/现场、家庭责任、搬迁意愿。
- 训练预算：学费、每周可投入小时、目标完成期限、收入缓冲月数。
- 国际路线追加：资格认可、目的地语言、当地经验、雇主担保关系、准证是否绑定雇主/职业。

允许用户对每项标记“证据充分 / 部分 / 尚无证据”，并上传前只在本机保存的笔记或链接；默认不收集敏感雇佣合同、健康诊断或护照信息。

## 风险面板

| 风险 | 估算内容 | 透明展示方式 |
|---|---|---|
| 收入 | 转型期降薪幅度、低薪持续月数、恢复至当前购买力的时间 | 本币工资 + PPP 余额；用户设定悲观/中位/乐观区间 |
| 技能 | 目标岗位必需技能、已有证据、缺口和对应训练任务 | 逐项列出岗位/官方职业资料来源；不以单一“适合度”代替 |
| 时间/资金 | 培训周期、课程/考试/执照支出、生活费与应急金 | 低/中/高成本及每周投入小时，注明估算人 |
| 需求不确定 | 招聘量/岗位空缺、工资分布、就业变化趋势、数据年份 | 统计趋势不是个人录用概率；小样本需显示低置信度 |
| 工作质量 | 合同工时、加班、通勤、强度、职业健康和排班 | 未知字段不计分；从 offer 和用户预算逐项补充 |
| 转型执行 | 作品集/面试/资格考试/入职里程碑是否完成 | 每个里程碑有检查日期和停止/继续条件 |
| 海外身份 | 工签是否绑定雇主/职业、失业缓冲期、换岗/转身份要求 | 引用目标国官方移民信息，并单列政策核对日期 |
| 可逆性 | 能否回到原行业、技能过期速度、是否需放弃执照/工龄权益 | 展示转回成本、可保留的证书/客户/作品和备份路线 |

风险分数可用“影响 × 暴露可能性 × 证据置信度”分项呈现。没有可靠个人/群体转职概率时，不输出精确成功率；用用户可调的范围和“需验证”的状态。

## 首版量化参考

为避免把量化分数误当作客观预测，职业转型首版采用用户可复核的情景输入：

- **技能缺口**：每项技能按 0–5 级填写当前水平和目标岗位要求，岗位重要度为权重 `wᵢ`。缺口分 = `100 × Σ[wᵢ × max(目标级别ᵢ − 当前级别ᵢ, 0)] ÷ Σ[wᵢ × 5]`。必需执照/资格另列为硬门槛，不能被平均分抵消。
- **证据强度**：作品/项目/绩效、近期实操、证书、仅自评分级记录；证据强弱不改写技能水平，但会降低“匹配置信度”。
- **收入回撤**：`(当前月可支配余额 − 转型情景月可支配余额) ÷ 当前月可支配余额`，同时展示本币金额和持续月数。余额为零或负数时不计算百分比，改显示金额差。
- **学习资金跑道**：`可用转型储备 ÷ max(月必要支出 + 月学习支出 − 转型期月收入, 0)`；分母为 0 时显示“当前情景现金流可覆盖”，不显示无穷大月数。
- **投资回本期**：当新岗位估计月可支配余额高于现路径时，`一次性训练/搬迁成本 ÷ 每月余额改善`；若余额改善不为正，标记“按当前假设无法回本”，不凑正数。
- **风险等级**：用户分别选影响度 1–5、暴露可能性 1–5，原始风险格为 `影响度 × 可能性`（1–25）；来源证据完整度单独展示，不拿置信度乘小风险分来掩盖未知。系统不给缺乏依据的百分比概率。
- **岗位需求趋势**：显示官方来源的就业人数/岗位空缺变化、工资范围与统计期；只作为外部环境证据，不转换成个人录用概率。

这些参数第一版属于决策脚手架，不是经过回测验证的预测器。默认权重应能调整，任何路线建议都要列出缺失输入和悲观/中位/乐观假设。

## 情景输出

每张路线卡显示：当前可比收入/有效时薪、过渡期现金流、训练缺口、预计决策日期、目标岗位数据年份、移民身份兼容性、关键不确定项和回退方案。提供三个可调情景：

- **稳健**：维持现金流，边工作边补技能，以真实面试/作品反馈为进度门槛。
- **平衡**：投入有期限的系统学习，设定储蓄缓冲与阶段检查点。
- **快速切换**：在确认资金、入门岗位和合法身份后集中转型；明确承受的最大收入回撤。

阶段门槛示例：完成一个可展示作品 → 找目标岗位从业者评审 → 获得面试/雇主反馈 → 核对最低可接受薪酬 → 再决定是否增加训练投入。它们是用户的决策检查点，不是系统保证就业的时间承诺。

## 公开数据源方向

- [美国 BLS 职业就业预测与工资/教育特征](https://www.bls.gov/emp/tables/occupational-projections-and-characteristics.htm)
- [澳大利亚 Jobs and Skills Australia 职业就业预测](https://www.jobsandskills.gov.au/data/employment-projections)
- [日本厚生劳动省 job tag 职业、任务与技能信息](https://shigoto.mhlw.go.jp/User/)
- [加拿大政府 Job Bank 工资与职业展望](https://www.jobbank.gc.ca/trend-analysis)
- 各国职业协会、执照主管部门和当地官方就业服务机构提供的资格/岗位信息。

不同国家职业分类不一致，必须先展示来源职业代码及映射关系，再比较相邻职业。预测数据只用于分析供需方向，不代表用户个人找工作成功率。

## 页面原型已实现

仪表盘中的“职业转型情景”支持本地填写当前及目标税后收入/必要支出、转型期间收入、储备金、一次性培训或搬迁成本、每月培训费用、每周学习小时和资格状态，并输入悲观 / 基准 / 乐观的目标收入。结果按每个情景展示目标月结余、相对当前结余变化、现金跑道和前置成本回本期。

用户可添加多项技能，按 0–5 级填写当前与目标、按 1–5 级填写重要度，技能缺口依加权公式计算；证据状态单独保留。风险项按影响度 × 暴露可能性计算 1–25 风险格，最高项单独展示，证据不与风险分相乘。页面用 1–5 / 6–10 / 11–15 / 16–25 标记低 / 中 / 高 / 很高，这些是便于排序的刻度分段，不是校准后的预测等级。资格未满足或待核实会触发核对提示。所有情景保存在 `localStorage`，不与公开工资数据合并，也不推断成功概率。

现金跑道按 `(转型储备 − 一次性前置成本) ÷ max(转型后必要支出 + 每月培训费 − 转型期间预计税后月收入, 0)` 估算；若月度现金流非负则提示可覆盖，前置成本高于储备时显示资金差额。回本参考按 `一次性前置成本 ÷ (转型后月结余 − 当前月结余)` 计算，只在月结余改善为正时显示月份。该原型未估算税务、资格审批、招聘成功概率或收入恢复时间，用户需自行核验输入和目的地规则。
