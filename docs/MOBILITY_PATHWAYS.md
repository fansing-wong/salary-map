# 出海工作与长期居留路径

本模块用于比较“先短居体验 → 合法工作 → 长期/永久居留 → 入籍”的可能路线。它提供官方入口和路线筛选，不代替移民律师、持牌顾问或政府资格审查。任何身份是否可工作都以签证/居留许可的具体条款为准。

## 通用阶段

| 阶段 | 可规划的路线 | 决策边界 |
|---|---|---|
| 0. 探路 | 商务/访客短停、语言或短期学习、当地招聘面试 | 访客身份通常不允许受雇；必须以目的地官方条款为准，不能把旅游签当工作签 |
| 1. 短期居住 | 工作假期/青年流动、短期雇佣、学习、合法求职或创业准备类许可 | 名额、国籍、年龄、保险、资金和可工作范围常有限制；完成期限不等于移民资格 |
| 2. 工作落地 | 雇主担保、积分/技能类、公司内部调派、毕业后工作许可、人才/杰出能力、指定行业、家庭团聚工作权 | 先核实职业/学历认证、语言、薪资门槛、雇主担保资格、工作权和许可绑定条件 |
| 3. 长居/永居 | 技术类直接永居、工作许可转永居、区域/省州提名、积分居留、家庭类、投资/创业类 | 临时签证、学生签或工作年限不自动产生永居权；离境天数、纳税、收入和品行会影响资格 |
| 4. 入籍 | 永居后满足居住、语言/考试、品行及其他条件再申请 | 入籍年限的起算点及双重国籍处理各国不同；先核实现国籍法律和目的国法律 |

## 目的地路线清单

以下路线是“应检查的官方类别”，不是对个人成功率的承诺。括号内为政府入口；签证名称、门槛和名额可能调整。

### 加拿大

- **短居/体验：** 访客短停；符合国籍互惠计划者可查 International Experience Canada（IEC）青年流动/工作假期。
- **工作：** 雇主特定或开放式工作许可；公司内部调派；符合条件的省区项目、法语/区域项目；毕业后工作许可（PGWP）须核对学校、课程与毕业时间资格。
- **转永居：** Express Entry（CEC、FSW、FST）；省提名 PNP；大西洋、农村/法语社区等区域项目；家庭团聚。学生毕业或有工作许可都不保证获邀/获批。
- **入籍：** 先取得有效 PR；成人申请一般按申请前五年内实际居住天数、语言、税务申报等条件核验。
- 官方入口：[工签类别](https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada.html) · [永久移民项目](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada.html) · [Express Entry](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry.html) · [IEC](https://www.canada.ca/en/immigration-refugees-citizenship/services/work-canada/iec.html) · [入籍资格](https://www.canada.ca/en/immigration-refugees-citizenship/services/canadian-citizenship/adult-minor/who.html)

### 澳大利亚

- **短居/体验：** 访客短停；符合国籍/年龄/名额条件可查 Working Holiday 417 或 Work and Holiday 462。
- **工作：** Skills in Demand 雇主担保 482；州/领地提名 190；独立技术 189；偏远地区 491；跨国公司调派等适用类别；符合资格的留学生毕业后可查 485。
- **转永居：** 雇主担保 186；491 后续区域永居 191；189/190 本身属于永居类别；伴侣/家庭类别。485 是临时通道，不保证转永居。
- **入籍：** 通常先持永久签证并达到居住、品行等要求；使用政府居住计算器核验离境天数。
- 官方入口：[工作签证选项](https://immi.homeaffairs.gov.au/visas/working-in-australia) · [雇主担保比较](https://immi.homeaffairs.gov.au/employer-subsite/Pages/compare-sponsored-skilled-visa-options.aspx) · [毕业生签证](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/temporary-graduate-485) · [入籍](https://immi.homeaffairs.gov.au/citizenship/become-a-citizen/permanent-resident)

### 日本

- **短居/体验：** 短期访日不产生工作权；与日本签有计划的国籍/年龄可查 Working Holiday。高学历毕业生可核对 J-Find 求职/创业准备资格。
- **工作：** 雇主合同下的“技术・人文知识・国际业务”等在留资格；高度专业职积分制；J-Skip 特别高度人才；公司内转勤；特定技能（行业和技能要求）；创业签证取决于地方政府项目。
- **转永住：** 普通工作/居留路径按现行永住指南审查；高度人才可按积分和连续在留条件走缩短路径；家庭关系另有类别。
- **入籍：** 与永住是不同申请。日本法务省一般归化说明列有连续住所、有效在留、品行、生计等条件；需单独核实原国籍的丧失/放弃后果。
- 官方入口：[在留资格/工作](https://www.moj.go.jp/isa/applications/status/index.html) · [高度人才](https://www.moj.go.jp/isa/publications/materials/newimmiact_3.html) · [永住指南](https://www.moj.go.jp/isa/applications/procedures/16-4.html) · [归化 FAQ](https://www.moj.go.jp/EN/MINJI/minji78.html)

### 韩国

- **短居/体验：** 短期访问；与韩国有协定且符合国籍/年龄要求时查 H-1 工作假期；特定优秀人才可查求职/准备类 D-10。
- **工作：** 专业岗位 E-7；公司调派 D-7；指定行业/国籍的 E-9；毕业后求职再转工作资格；配偶 F-6 等家庭路线。
- **转长期/永居：** E-1–E-7 等工作资格可按条件申请 F-2 居留；积分制 F-2-7；符合细分条件后申请 F-5 永居。不同职业和在留资格的年限、收入、韩语/社会融入要求不相同。
- **入籍：** 一般归化、简易归化及特别归化条件不同，需通过韩国法务部官方指南核实；不能仅凭工作年限推断。
- 官方入口：[韩国出入境/签证指南](https://www.immigration.go.kr/immigration_eng/index.do) · [签证类别与长期居留指南](https://www.immigration.go.kr/bbs/immigration_eng/230/454085/download.do) · [E-7 官方指南](https://www.immigration.go.kr/sites/immigration/file/e7guide.html)

### 美国

- **短居/体验：** 访客或商务访问不得作为普通受雇工作许可；交流访问 J-1 仅限批准项目/活动。
- **工作：** 雇主申请 H-1B 专业岗位；L-1 公司内部调派；O-1 杰出能力；TN（加拿大/墨西哥特定职业）；E-3（澳大利亚特定专业人员）；学生 F-1 在符合规则时可用 CPT/OPT 实习/毕业后工作。
- **转绿卡：** 雇主职业移民 EB-1/EB-2/EB-3；符合条件者 EB-2 NIW；家庭类。临时工签和 OPT 均不自动形成绿卡资格。
- **入籍：** 通常先成为 LPR/绿卡持有人，再满足居住、品行、英语/公民考试等要求；具体类别例外需核对 USCIS。
- 官方入口：[临时工作签证](https://www.uscis.gov/working-in-the-united-states/temporary-workers) · [工作/移民类绿卡](https://www.uscis.gov/green-card/green-card-eligibility/green-card-for-employment-based-immigrants) · [入籍](https://www.uscis.gov/citizenship/learn-about-citizenship)

### 中国（适用于外籍人士来华工作/居留）

- **短居/体验：** 依国籍、访问目的和当期政策核对免签/签证停留规则；短期访问不等同于工作许可。
- **工作：** 通常需工作许可及工作类居留证件；雇主聘用、跨国公司派遣、符合条件的高层次人才等按工作许可类别申请；留学生校外工作另有审批/标注要求。
- **转永居：** 国家移民管理局公布的类别包括投资、任职/贡献、人才/特殊贡献、家庭关系等，按法定条件申请，不能视为普通工签的自动下一步。
- **入籍：** 可提出申请但须审批；官方申请指引要求提交自愿申请归化及放弃外国国籍的书面声明。需优先评估现国籍放弃的法律和个人影响。
- 官方入口：[外国人工作许可与居留法律](https://www.nia.gov.cn/n741440/n741547/c757592/content.html) · [永居条件](https://en.nia.gov.cn/n147423/n147478/n147715/c158291/content.html) · [归化申请](https://en.nia.gov.cn/n147423/n147478/n147720/c158308/content.html)

### 英国、新加坡（覆盖原型已有市场）

- **英国：** Skilled Worker / Health and Care Worker、Global Talent、Graduate（临时）、Global Business Mobility/公司调派、家庭等；后续按具体路径评估 ILR，再评估入籍。 [工作签证](https://www.gov.uk/browse/visas-immigration/work-visas) · [ILR](https://www.gov.uk/indefinite-leave-to-remain-tier-2-t2-skilled-worker-visa/overview)
- **新加坡：** Employment Pass / S Pass 雇主聘用；符合条件者 ONE Pass、EntrePass 或内部调派；之后可向 ICA 申请 PR，PR 后再按 ICA 规则评估公民申请。PR/入籍均属个案审查，不承诺审批。 [MOM 工作准证](https://www.mom.gov.sg/passes-and-permits) · [ICA 永居/公民](https://www.ica.gov.sg/information-and-e-services/citizenship-and-permanent-residence)

## 产品中的匹配与排序

用户选择当前国家、目标国家/地区、职业、年龄段、学历、工作年限、语言、预算和愿意投入时间后，路线卡片按以下条件筛选：

1. **硬性门槛**：国籍/年龄协定、职业资质、雇主担保、薪资/积分/语言门槛、家庭条件、资金证明。
2. **阶段入口**：短居探索、立即就业、先读书/求职、内部调派、直接永居、家庭或创业。
3. **长期路径**：每条路线分别展示“临时身份 → 工作权 → PR/永居 → 入籍”是否存在官方衔接，以及哪些步骤不保证成功。
4. **生活与职业排序**：接入薪酬地图中同职业的 PPP 后余额、有效时薪、工时和强度；再扣除搬迁成本、语言/认证、签证成本与求职空档。金额和移民可行性分开评分。
5. **证据与更新时间**：每条规则保留政府链接、核对日期、适用对象和页面版本；对规则变更设置复核队列。用户最终须回官方页面核对。

首版先提供国家/路径对照与个人条件清单；不自动生成法律结论、不代填申请、不抓取商业中介的资格承诺。移民政策高度变化，路线库需在每次发布时检查官方链接和日期。
