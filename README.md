# 薪酬地图 | Salary Map

一个面向跨地域择业的开源决策仪表盘。比较岗位税前工资、通勤与加班后的有效时薪、估算生活成本、购买力余额和主观劳动强度。无需安装依赖，支持 GitHub Pages 静态部署。

## 使用

直接打开 `index.html`，或通过 GitHub Pages 发布仓库根目录。表格中的机会可添加、编辑、删除；数据保存在当前浏览器的 `localStorage`。点“恢复演示数据”可重置本地记录。

## 指标

- **有效周工时** = 合同周工时 + 每周加班 + 每周通勤时间。通勤时间按个人时间成本计入，不代表法律意义的工作时间。
- **实际时薪** = 月薪 × 12 ÷ (有效周工时 × 52)。这是税前估算，不计奖金、税、社保或带薪假期；缺少合同工时、加班或通勤数据时留空。
- **购买力余额** = 税后到手月收入 − 单人每月基本生活成本估算。若只有税前工资，需在“预算/强度”中补填实际到手收入；未提供时购买力余额和总分留空。
- **推荐分**是透明的 0–100 排序参考：默认权重为税后购买力结余 40%、有效时薪比较 35%、劳动强度 15%、资料完整度 10%；可切换均衡、购买力优先、时薪优先、低强度优先方案，也可调整并保存多个本机方案；机会表会显示其在四种内置方案下进入前3的次数，帮助识别偏好敏感的排名。该次数只在至少4个候选可评分、且至少两种预设可比较时展示；并列会计入前3。它是方案一致性，不是成功概率或置信度。权重自动归一化为 100%，仅保存在当前浏览器。有效时薪按筛选组百分位计算，小于 5 条时向中位分收缩；缺少正权重项的关键数据时不计算总分。公式、百分位样本数和完整度字段见页面“计算方法”。
- **劳动强度**为 1–5 主观评分，建议按体力负担、工作节奏、压力和排班综合填写。

## 数据

内置记录是**模拟演示数据**，不代表任何官方统计、城市平均薪资或生活成本。请以实际 offer 和可核验的当地数据替换。用户自定义数据只存放在浏览器本地，不会传到服务器。

当前的地域对照支持“同职业比地域”和“同地域比职业”，并可沿国家/地区、省州或大区、城市筛选；选择“我的本国”后，可切换查看本国与海外。具体覆盖取决于已载入数据源，未发布到城市层级的统计不会下推到城市。

页面的“国家数据覆盖”矩阵逐国汇总已发布的官方工资记录、岗位组、地域层级和参考期，并列出尚待接入的官方来源。矩阵只统计公共数据文件中的可追溯记录，不计入本机个人输入或模拟数据。

已纳入官方数据底座和接入计划的来源：

- [新加坡人力部 MOM 职业工资](https://stats.mom.gov.sg/statistics/income/occupational-wages/)
- [美国劳工统计局 BLS OEWS 职业工资表](https://www.bls.gov/oes/tables.htm)
- [加拿大 Statistics Canada 年度职业工资表](https://www150.statcan.gc.ca/n1/en/catalogue/1410041701)
- [英国 ONS 工资与工时统计](https://www.ons.gov.uk/employmentandlabourmarket/peopleinwork/earningsandworkinghours)
- [中国国家统计局城镇工资（2025）](https://www.stats.gov.cn/english/PressRelease/202605/t20260518_1963740.html)
- [日本厚生劳动省工资统计](https://www.mhlw.go.jp/www2/info/toukei/english/surveys.htm)
- [韩国雇佣劳动部工资与工时](https://stathtml.moel.go.kr/statHtml/statHtml.do?conn_path=I2&language=en&orgId=118&tblId=DT_118N_LCE0001)
- [澳大利亚 ABS 工资与工时](https://www.abs.gov.au/statistics/labour/earnings-and-working-conditions/employee-earnings-and-hours-australia/may-2025)

各国统计口径、税前/税后定义、职业分类和年份不同，整合前应保留原始来源、统计年份、样本口径及币种，避免把平均值、中位数和招聘报价混为一谈。

## 贡献

欢迎提交各地官方数据适配器、来源元信息、经验证的生活成本预算或翻译。新增数据请标明来源 URL、发布日期/参考期、币种、平均数或中位数、税前/税后、工时口径和许可条件。不要将模拟值描述为真实市场数据。

## 自动更新数据

刷新入口为 `scripts/refresh_data.py`，分别更新 BLS 工资数据、获准的公开 CSV 来源和宏观指标。把获得授权且可再分发的 CSV 来源加入 `scripts/sources.json` 后，可本地运行 `python scripts/refresh_data.py`。GitHub Actions 每周一 UTC 04:17 自动运行，也可在 Actions 页面手动触发；数据写入 `data/latest.json` 和 `data/macro.json`，运行状态记录在 `data/status.json` 并显示于仪表盘。首次上线时 CSV 来源列表为空，因此不会自动抓取网站。

各数据文件在校验完整后才原子替换。单一来源失败不会阻断其他刷新；状态文件记录本轮结果和上次成功时间，真实数据/网络错误会让 Actions 运行标记为失败，同时继续提供上次成功快照。若 robots.txt 明确禁止某来源，系统将其标为“受限”，保留旧快照并发出警告，不会绕过限制。仪表盘在工资统计参考期超过 2 年、汇率日期超过 7 天或 PPP 参考年超过 3 年时提示复核；这些是项目提醒阈值，不代表来源机构的官方有效期。

采集器会检查 robots.txt、发送带说明的 User-Agent、使用条件请求并限制请求频率。来源应提供规范 CSV，字段映射和口径需在来源注册表中声明。当前脚手架不是通用网页解析器，也不会抓取需登录内容。

社交平台数据应仅通过获准的官方 API 或获得授权的导出数据接入，并单独标注为招聘帖子样本；不能代表岗位平均薪资。LinkedIn 的帖子读取权限有审批限制，见 [LinkedIn API permissions](https://learn.microsoft.com/en-us/linkedin/shared/authentication/getting-access)。未经授权抓取账号内容会因平台规则和技术限制而不稳定。抓取公开站点也要尊重站点规则；`robots.txt` 是抓取偏好机制，不等于许可或法律意见，见 [Google robots.txt guidance](https://developers.google.com/search/docs/crawling-indexing/robots/intro)。

后续版本规划见 [产品路线图](docs/PRODUCT_ROADMAP.md)、[国家数据覆盖计划](docs/COUNTRY_COVERAGE.md) 和 [出海工作/居留路径](docs/MOBILITY_PATHWAYS.md) 和 [职业转型情景](docs/CAREER_SCENARIOS.md)。

## 跨币种购买力

页面可选择展示币种，名义金额由欧洲央行每日欧元参考汇率交叉换算，并标出汇率日期。PPP 近似使用世界银行家庭消费价格水平指数（美国=100）将名义美元换算为国际元估算；这是国家级家庭消费价格代理，不是城市租金或个人消费篮子。宏观数据由 `scripts/update_macro.py` 更新到 `data/macro.json`。首次刷新前或缺失地区不会显示跨区 PPP 值；不以 0 或模拟数填补。

用户机会可填写统计口径、税前/税后、参考期、来源名称及链接。演示记录始终标为模拟样例。世界银行指出 PPP 适用于家庭最终消费等宏观总量比较，不能直接代替具体工资或个人支出测量；请把 PPP 作为预算情景参考，而非税后购买力承诺。


## 首个官方薪资源：美国 BLS OEWS

刷新任务从 BLS 官方 May 2025 Metropolitan and Nonmetropolitan Area 数据包读取都市区职业工资中位数，筛选跨行业详细职业行，导入软件开发人员、注册护士、数据科学家和零售销售员。每行保留 SOC 职业代码、统计期、原始来源链接和抓取时间。BLS 城市工资表不提供生活成本、通勤、加班或劳动强度，因此这些字段保持未知；税后到手收入、生活成本/PPP 余额、加班/通勤和强度需按个人情景补充；任一核心项未知时不显示总分。

BLS 官方数据表：[OEWS Tables](https://www.bls.gov/oes/tables.htm)。May 2025 表格提供全国、州、都市区和非都市区估计；职业工资中位数是地区/职业层级统计，不代表具体职位 offer。

## 个人预算与强度情景

官方统计记录的生活成本、加班、通勤和岗位强度由“预算/强度”入口单独录入，保存在浏览器本地的独立设定中。更新工资数据不会覆盖这些个人输入；点“清除个人设定”即可恢复未知状态。预算和强度未补全时，系统不生成综合推荐分。

## 职业转型情景

“职业转型情景”可以记录当前/目标税后收入、转型期间收入、必要支出、转型储备、前置费用、学习投入和目标资格状态；用户可自行添加技能项、重要度、证据状态及影响度 × 暴露可能性风险格。工具并列显示悲观、基准、乐观三种用户输入，不估算个人录用概率。数据只保存在本机浏览器；清除情景不会影响薪资机会数据。

## 出海路径浏览器

页面按目的地国家和五个阶段筛选政府移民入口：短期探路、短居/青年流动、合法工作、长期/永久居留和入籍。初始覆盖美国、加拿大、澳大利亚、英国、新加坡、日本、韩国和中国。入口清单不判定某人的国籍、年龄或资历是否符合条件，也不替代最新法规核验；具体路线的细节和边界见 [出海路径说明](docs/MOBILITY_PATHWAYS.md)。
